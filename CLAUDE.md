# Cinematic Scroll Portfolio

## What this is
Personal portfolio site with cinematic, video-driven scroll animations.
Smooth page transitions, GSAP-powered motion, Lenis for inertia scrolling.

## Tech stack
- Next.js (App Router) + TypeScript
- GSAP — scroll-triggered animations, timeline sequences
- Lenis — smooth scroll inertia
- Framer Motion — component-level transitions
- Tailwind CSS

## Key files
- `src/` — main source directory
- `scripts/` — build or animation helpers
- `public/` — video assets, images

## Run
```bash
npm run dev     # localhost:3000
```

## Goal
Every section should feel like a film frame. Scroll performance must stay
above 60fps. Animations should reinforce content hierarchy, not distract.
