
Later recommendation: buy `akshaykeerthi.com`.

Reasons:

- It is the clearest personal brand domain.
- It is cheaper than `.io`.
- It is better for a broad professional portfolio than `.dev`, which reads more narrowly technical.
- It will look natural for AdSense review, email, resumes, and portfolio sharing.

For the temporary free domain, set:

```bash
NEXT_PUBLIC_SITE_URL=https://akshaykeerthi-portfolio.vercel.app
CONTACT_TO_EMAIL=hello@akshaykeerthi-portfolio.vercel.app
CONTACT_FROM_EMAIL=Portfolio <hello@akshaykeerthi-portfolio.vercel.app>
```

After buying/attaching `akshaykeerthi.com`, set:

```bash
NEXT_PUBLIC_SITE_URL=https://akshaykeerthi.com
CONTACT_TO_EMAIL=hello@akshaykeerthi.com
CONTACT_FROM_EMAIL=Portfolio <hello@akshaykeerthi.com>
```

Domain prices and availability can change; re-check before purchase.
